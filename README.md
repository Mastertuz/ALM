# ALM — Алгоритмы машинного обучения для решения прикладных задач

МИРЭА, семестр 1. Задания практических занятий и их решения.

## Структура репозитория

- Ветка `main` — задания (`tasks/`) и общая информация.
- Ветка `pr1` — Практическое занятие №1-2: парная линейная регрессия (гиперспектр кукурузы).
- Ветка `pr2` — Практическое занятие №3-4: логистическая регрессия / классификация (winequality-red).
- Ветка `pr3` — зарезервирована под следующую практическую работу (задание пока не выдано).

Каждая ветка с практической работой содержит только относящиеся к ней файлы (ноутбук, данные, README с описанием задания).
